# Decisions
* [ADR-001: Design It Twice Evaluation for Compositor and Session Seams](adr-001-design-it-twice-compositor-seam.md) - Comparison of four candidate module interfaces and selection of a Sans-I/O Compositor core paired with a Session runner.
* [ADR-002: Internal Module Decomposition and Ratatui-Style 2D UI Buffer Seam](adr-002-modular-decomposition-and-ui-buffer-seam.md) - Decomposes monolithic compositor/session/config modules into focused submodules and introduces a Ratatui-inspired 2D Buffer/Span/Line/Widget rendering foundation in src/ui/.
* [Performance Deepening, Frame Pacing, and Zero-Allocation Cell Grid](adr-003-performance-deepening-and-frame-pacing.md) - Decouple PTY byte ingestion from 144 FPS frame composition, replace heap String Cells with inline scalar chars in Buffer, introduce run-length cursor tracking in ANSI diffs, and isolate OS telemetry probes behind an asynchronous cache seam.
* [ADR-004: SessionLoop and SessionIo Internal Seam](adr-004-session-loop-and-session-io-seam.md) - Consolidate all session runtime policies into a crate-internal SessionLoop driven over a single SessionIo port trait with OS and in-memory adapters, replacing HeadlessHarness.
* [ADR-005: CommandScheduler, Typed Command Keys, and Filesystem Checks Behind SessionIo](adr-005-command-scheduler-and-typed-command-keys.md) - Consolidate command scheduling into a CommandScheduler inside Compositor with typed command keys, move when_files filesystem checks behind SessionIo, and prevent overlapping and stale command runs.
* [ADR-006: InheritedSession Assessment and Explicit THUD_* Environment Handling](adr-006-inherited-session-and-thud-env.md) - Replace scattered THUD_* environment reads, purges, and string-matched errors with a pure InheritedSession assessment, explicit child environment construction, and typed session errors.
* [ADR-007: HudPainter, Closed TelemetryStore, and Themed Toast Placement](adr-007-hud-painter-and-closed-telemetry-store.md) - Move widget evaluation and HUD painting out of TelemetryStore into a HudPainter, close TelemetryStore behind read queries, unify the widget walk, and place toast stacks through PlacementSolver with collision avoidance and theme colors.
* [ADR-008: InputRouter and Host Terminal Mode Mirroring](adr-008-input-router-and-host-mode-mirroring.md) - Move host input classification into an InputRouter that holds split mouse reports and treats bracketed pastes as opaque, mirror child terminal modes to the host, and validate hotkeys at config load.
